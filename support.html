Support

Stuck? Let's fix it before soundcheck.

Most issues are one keyboard setting away from working. Check the FAQ below, and if you're still stuck, email us — MIDI questions welcome, firmware quirks and all.

Frequently asked

Learn doesn't capture anything when I select a performance
Learn is one of the optional Two-way MIDI features (Settings → Two-way MIDI) — you never need it: type the performance's Live Set Page and Slot and press Try it instead. If you do want Learn, the keyboard has to transmit its selection. On the MODX: Utility → Settings → Advanced → set Bank Select and Pgm Change to ON (they gate transmit and receive for the whole instrument). Also check Utility → Settings → MIDI I/O has MIDI IN/OUT = USB. Then use the built-in MIDI monitor (Tools menu) to confirm messages arrive when you switch performances on the panel.

Monitor shows only CC messages (e.g. CC 16, CC 95) when you switch? Those are knob/controller resets — the selection itself isn't being transmitted. Two more gates on the MODX: the MIDI I/O Mode must be Single (or Hybrid), and Zone Master must be OFF (Zone Master replaces panel transmit with per-zone settings — Learn stays silent unless the zone itself transmits Bank/PC).

Meanwhile, you're never stuck: on the keyboard, tap the performance's name → Property to see its MSB/LSB/PC, and type those into the app — the number fields accept direct typing.
Nothing happens when I select a song — is it the app or the cable?
First, look at the connection indicator (Windows: bottom-right of the window; mobile: the keyboard icon in the top bar) and press Try it in the song's editor. If that doesn't switch the keyboard either, check the three receive settings on the install page. For a deeper check, switch on Two-way MIDI and use Check connection (Windows: Tools → Settings → Two-way MIDI → Keyboard link; mobile: Settings → Advanced). It asks the keyboard to identify itself and reports back, which separates the three things that look identical from the stage:
  • It names your keyboard → the cable, the ports and two-way MIDI all work. Any remaining problem is the address, so re-enter the song's sound (Try it to check) or use Live Set addressing.
  • No reply → the keyboard isn't talking back. Check the USB cable (or OTG adapter), that both ports point at the keyboard, and that MIDI IN/OUT is set to USB.
  • It names a different brand → you're on the wrong keyboard profile; change it in Settings.
The check only asks "who are you?" — it never changes a setting on your instrument.
A few specific performances won't switch (often organs) — use Live Set
Some Yamaha performances don't respond at the bank numbers their Property screen shows — it's inconsistent, and organ/tonewheel sounds seem worst affected. Rather than hunt bank numbers, switch the app to the Yamaha Montage / MODX — Live Set keyboard profile (Settings → Keyboard):
  1. On the keyboard, put the performances you gig into Live Set pages (press LIVE SET, hold a slot to assign the current performance).
  2. In the app, each song is then just Page (1–16) and Slot (1–16) — exactly what you see on the Live Set screen. No bank numbers at all.
  3. Learn still works: open Live Set on the keyboard and touch the slot.
Live Set is one fixed bank, so this addressing is exact for every performance — and it's how most players organize a gig anyway.
Some performances switch fine, but layered/split ones don't
That's the keyboard's MIDI I/O Mode. On the MODX: Utility → Settings → Advanced (not the MIDI I/O page) → set MIDI I/O Mode to SINGLE. In Multi mode an incoming Program Change only changes Part 1, so single-part sounds (many pianos) appear to work while layered or split performances (organs, pads, splits) don't switch as a whole. In Single mode the app selects entire performances, every time.

Don't see "MIDI I/O Mode" on the Advanced page? Your MODX firmware predates it — the mode selector arrived with MODX OS v2.0 (current: v2.52, a free update from Yamaha). Check your version under Utility → Other Info, then update via USB stick following Yamaha's updater page. Back up your user data to USB first.

MODX M / MONTAGE M note: same setting, same fix. One extra quirk on the M generation: whole performances live at Bank MSB 64 (MSB 63 recalls a sound as a single part) — Live Set addressing sidesteps it entirely; if you type bank numbers by hand, use the ones the keyboard shows under performance name → Property.
Windows says the app is unrecognized / SmartScreen warning
Normal for a small independent app that isn't yet code-signed. Click More info → Run anyway. The app is fully offline, makes no network connections, and writes only to its own settings folder (%APPDATA%\ModxManager\).
The program numbers don't match my keyboard
They should — that's a feature. The PC field is shown 1-based to match the Yamaha panel: if the keyboard shows performance 51, type 51. (MIDI itself counts from 0; the app converts internally.) Easiest of all: use the Live Set profile — just Page and Slot, exactly as the Live Set screen shows them — and press Try it to hear it.
My footswitch advances twice, or also sustains notes
A Bluetooth page-turner needs no setup at all. For a pedal plugged into the keyboard (a Two-way MIDI feature), re-capture it in Settings → Two-way MIDI → Footswitch — the app triggers on the rising edge and debounces, so one physical press is one advance. If you captured the sustain pedal (CC 64) the app warns you, because that pedal also sustains notes; use an assignable switch instead and set it to transmit via Utility → Controller / MIDI I/O.
Does it work without a MIDI connection?
Yes. You can build the library, read and annotate charts, and run setlists with no keyboard attached — performance switching just shows a gentle note instead of failing.
Which keyboards are supported?
Yamaha MODX / MODX+ / Montage are hardware-verified. Generic profiles (Program Change only, or MSB + PC) cover most other keyboards that accept program changes. Dedicated Nord, Korg, Roland and Kurzweil profiles are on the roadmap as hardware verification completes — if you own one and want to help test, we'd love to hear from you.
Where is my data? Can I move it to another computer?
Everything lives in %APPDATA%\ModxManager\ — library.json and settings.json — plus your own PDF files wherever you keep them. Copy the folder (and your PDFs) to migrate. Saves are atomic with a .bak backup kept.
Can I use it on Android or iPad?
Android: yes — see the install page (Android 7.0+, USB-OTG). It can import your desktop library.json directly. iPad is in progress and coming to the App Store.
