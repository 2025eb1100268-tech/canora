System requirements

PlatformRequirement
WindowsWindows 10/11, 64-bit. Runs great on older, low-RAM laptops — that's what it was built for. No Python or other software needed.
AndroidAndroid 7.0 (API 24) or newer; USB-OTG for MIDI.
KeyboardYamaha MODX / MODX+ / Montage fully verified. Any keyboard that accepts Program Change works via the generic profiles.
CableOne standard USB cable (the "printer cable" your keyboard already uses).

Your library and settings live in %APPDATA%\ModxManager\ — never next to the .exe, so the app runs fine from a read-only location and survives updates untouched.

First-time setup — 3 steps

  1. Connect the keyboard to the PC with the USB cable and power it on.
  2. Pick your keyboard: launch the app — if the keyboard is the only MIDI device it is picked for you. Otherwise open Tools → Settings and set the MIDI output port to your keyboard (e.g. MODX-1) and the MIDI channel (1 by default).
  3. Add a song, type its Live Set Page and Slot, and press Try it — the keyboard switches. The bottom-right corner always shows whether the keyboard is connected.

Three settings on the keyboard itself

On the MODX, in Utility → Settings → MIDI I/O: set MIDI IN/OUT to USB and the MIDI channel to match the app. In Utility → Settings → Advanced: make sure Bank Select and Pgm Change are ON (they govern receiving too), and set MIDI I/O Mode to SINGLE — in Multi mode, layered and split performances won't switch from the app. That is all changing sounds needs; the optional Two-way MIDI features (Learn, MIDI footswitch, Soundcheck) also need the keyboard to transmit — see the support page.

No keyboard handy? The app runs fine without one — you can build your library and read charts anywhere; performance switching just shows a gentle reminder.
